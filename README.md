# TOPDRESS — сайт салона свадебной и вечерней моды

Статический сайт по образцу `site-Gornica`. Открыть: `index.html` в браузере — сборка и библиотеки не нужны.

**Опубликован:** https://svladimirko-arch.github.io/topdress/ (GitHub Pages из ветки `main`, репозиторий `svladimirko-arch/topdress`). Ярлык `Ярлык сайта TOPDRESS.url` в этой папке открывает опубликованную страницу.

**Видео:** `TOPDRESS_site_video_TEST_na_soglasovanie.mp4` — тестовый ролик 48 с (1920×1080, 30 fps), снятый по образцу GORNICA из скриншотов этого сайта. Имя с `TEST` сохраняется до подтверждения визуала и звука; после «ок» файл переименуется без пометки. Видео намеренно не попадает в git (`.gitignore` → `*.mp4`).

## Источник данных

Все контакты, адрес, часы, оценка, отзывы, цены и фотографии взяты из карточки 2ГИС:

`https://2gis.ru/kazan/firm/70000001034630663`

- 46 фотографий: 7 статичных блоков + 30 в галерее + 9 в ленте «Атмосфера» — столько же, сколько в сайте-референсе.
- Кадры отобраны из галереи 2ГИС; исключены повторы и фото без лиц. У нижнего края обрезаны 4,5 % кадра.
- Тексты отзывов приведены дословно, выбраны только положительные.
- Цены подписаны как данные 2ГИС; цены не являются публичной офертой. Рейтинг на сайте не публикуется.

## Что где менять

- `assets/config.js` — контакты, соцсети, карта, оценка, галерея, «Атмосфера», отзывы, подключение заявок.
- `index.html` — тексты блоков, SEO, JSON-LD, юридические диалоги внизу файла.
- `assets/style.css` — оформление; `assets/app.js` — поведение (галерея, лайтбокс, фильтры, форма, карта).
- `tools/prep_images.py` — подготовка новых фото из исходников; `tools/adapt_index.py` — адаптация шаблона GORNICA; `tools/verify_site.py` — проверка конфига и файлов.

## Заявки с формы

Пока `lead.endpoint` в `config.js` пуст, форма проверяет поля и честно сообщает, что заявка не отправлена: предлагает позвонить, написать в WhatsApp / Telegram / Max или скопировать текст заявки. Чтобы получать заявки, разверните обработчик (пример — `tools/telegram-worker.js`) и укажите его адрес в `lead.endpoint`. Сайт отправляет JSON: `name, phone, direction, date, comment, page, utm, ts`.

## Проверка перед публикацией

```powershell
python tools/verify_site.py
```

- Метка карты задана в `contacts.mapSrc` (`49.10733, 55.786865`) — проверьте положение после публикации.
- Юридические тексты в `dlg-privacy` и `dlg-consent` помечены как заглушки; замените на утверждённые салоном редакции с реквизитами оператора.
- `og:image` и `image` в JSON-LD указывают на локальный `images/hero-l.webp`; при переносе на отдельный домен замените их на абсолютный адрес сайта.
- `canonical` и `og:url` намеренно не указаны: при публикации на GitHub Pages достаточно относительного адреса, канонический адрес можно добавить после переезда на собственный домен.
